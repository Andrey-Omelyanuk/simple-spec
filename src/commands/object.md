# /object

Режим работы с объектом: обсуждение, редактирование и — по явному указанию —
правка кода. Объект — единица спеки, с которой работает конечный пользователь.
Правила письма и шаблон объекта — `src/OBJECT.md`.

## Поток

1. **Найди или создай** объект в `oos/` (имя уникально внутри `oos/`).
2. **Прочти источники** — истории из раздела «Источник»: там контекст, зачем
   объект такой. При споре о поведении слова пользователя из истории — аргумент,
   который приносишь в обсуждение.
3. **Обсуди и правь** объект — состояния, поведение, границы. Объект править
   можно свободно, без отдельной команды.
4. **Жди явного указания** пользователя по коду — без него код и тесты не
   трогаешь.
5. **Правя код** — добавляй/обновляй тесты со ссылкой на объект
   (`// object: <имя>`); сверяйся с `Verification` уровня, чтобы понять, когда
   поведение покрыто. Что значит «реализован» и «баг» — README (Проекция).

## Чего ты НЕ делаешь

- Не трогаешь архитектуру.
- Не пишешь и не меняешь код автоматически: любая правка кода — только по явному
  указанию в чате. Правка самого объекта — исключение.
