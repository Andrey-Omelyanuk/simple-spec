# /do

Режим реализации. Запускается свежей сессией: контекста — файл истории в
`stories/` и `AGENTS.md` затронутых уровней — достаточно, история обсуждения не
нужна. Формат истории — в команде `src/commands/story.md`.

Реализуешь историю: `$ARGUMENTS`

## Поток

1. **Найди историю** в `stories/` по переданному имени (файл
   `ГГГГ-ММ-ДД-<имя>.md`). Имя не передали — спроси и не угадывай: `stories/` —
   лог, свежая запись в нём не обязательно та, которую просят. Истории нет
   вовсе — это мелочь: реализуй по указанию из чата.
2. **Прочитай уровни** — `AGENTS.md` затронутых папок: оттуда правила
   `Verification`. У затронутого уровня нет `AGENTS.md` — остановись и предложи
   `/architect`: без `Verification` нечем определить, чем проверять, и историю
   нельзя закрыть.
3. **Создай ветку** от главной. Имя ветки — имя истории без даты (`shop` для
   `stories/2026-08-24-shop.md`). Закоммить файл истории первым коммитом: ветка
   открывается историей, закроет её PR.
4. **Реализуй по пунктам** `## Поведение`:
   - тесты: имя теста повторяет формулировку пункта поведения. Сверяйся с
     `Verification` уровня;
   - решения, которые нельзя вывести из кода, — комментарием «почему» рядом с
     кодом или в `Non-Obvious Rules` уровня. Комментарий отвечает «почему», не
     «что»; самое ценное — отвергнутая альтернатива;
   - обнаружил поведение, которого нет в истории (краевой случай), — сначала
     допиши пункт в историю, потом тест. Дописывать можно только историю своей
     ветки и только до мержа; прежние пункты при этом не переписывают;
   - пункт отменяет поведение, покрытое тестом прошлой истории, — переформулируй
     или удали тот тест отдельным коммитом, а в сообщении коммита назови, что
     отменено и почему;
   - понадобился новый уровень — новый `AGENTS.md` по шаблону
     (`src/LEVEL.md`), в ту же ветку.
5. **Докажи**: прогони тесты уровня и покажи вывод — диф без прогона не
   результат. Затем выпиши проекцию: строка на пункт поведения, `пункт → имя
   теста`. Пункт без теста называй прямо и с причиной.
6. **Коммить** в ветку истории осмысленными шагами, затем **открой PR** в
   главную ветку: заголовок — имя истории, в теле — текст истории целиком и
   проекция из шага 5.

## Чего ты НЕ делаешь

- Не мержишь PR — это решение пользователя.
- Не удаляешь и не переписываешь пункты истории — только дописываешь; спор с
  историей возвращай в чат.
- Не трогаешь другие ветки.
