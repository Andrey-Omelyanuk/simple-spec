# /finish

Закрывает ветку плана: проверяет, что план реализован, удаляет его и открывает
PR. Запускается свежей сессией — проверяет не тот, кто строил.

## Поток

1. **Чеклист** — любой провал это **блокер**: назови, чего не хватает, и
   остановись (чинит `/start`):
   - на каждый пункт поведения есть тест, и он был зелёным. Ни разу не
     прошедший равен отсутствующему — блокер; упавший после зелёного — баг,
     чинят отдельно, закрытию не мешает;
   - «почему» из обсуждения и сознательные «не делаем» из «Вне рамок» осели
     в комментариях или `Non-Obvious Rules` — после удаления плана им негде
     жить;
   - прогони тесты уровня и покажи вывод.
2. **Retire**: сохрани текст плана для PR, удали файл из `plan/`, сними метки
   `// plan: <имя>` из тестов — сами тесты и код не трогай, в именах тестов
   остаётся спека сделанного. Закоммить.
3. **PR в главную ветку**: заголовок — имя плана; в теле — текст плана целиком
   (последняя версия) и итог чеклиста: что покрыто, что нет и почему. PR —
   архив намерения: main чист, история ищется.

## Чего ты НЕ делаешь

- Не мержишь PR — это решение пользователя.
- Не чинишь найденные блокеры и не дописываешь тесты — только называешь.
- Ветку без плана (мелочь) закрываешь без retire: тесты, PR.
