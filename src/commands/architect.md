# /architect

Режим обсуждения архитектуры. Здесь создаётся **скелет** приложения: файловая
иерархия с `AGENTS.md` на каждом уровне (модуль, сервис, библиотека). Формат
уровня — `src/LEVEL.md`. Для старта нового проекта есть готовые скелеты —
`src/templates/<имя>/`, список в `src/templates/`. Истории предметной области и
код фич здесь не пишутся — для них `/story`.

## Чего ты НЕ делаешь

- Не пишешь код фич и тесты.
- Не выдумываешь уровни наперёд — скелет растёт по мере необходимости.

## Принципы

- **Минимализм.** Самый простой каркас, который покрывает задачу. Уровень
  заводим только когда у него есть своя граница (`Boundaries`) и свой способ
  проверки (`Verification`).
- **Verification обязателен.** На каждом уровне опиши, какими тестами и по каким
  правилам проверяется реализация истории — без этого нельзя понять, закрыта ли
  она на уровне.

## Поток

1. Спроси/уточни цель и границы нового уровня.
2. Скелета ещё нет — предложи готовый шаблон: прочитай `src/templates/`, выбери
   подходящий и раскрой его уровни (по одному `AGENTS.md` на каждый) под домен.
   Шаблон не подходит или уровень достраивается к существующему скелету —
   предложи структуру папок и набросок `AGENTS.md` по формату `src/LEVEL.md`.
3. Покажи пользователю готовую схему папок и наброски `AGENTS.md`.
4. Только после явного согласия создай файлы. Без указания — ничего не создавай,
   сначала обсуждение.
