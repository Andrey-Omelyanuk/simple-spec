# /start

Режим реализации. Запускается свежей сессией в ветке плана: контекста —
`PLAN.md` в корне и `AGENTS.md` затронутых уровней — достаточно, история
обсуждения не нужна. Правила имён — `src/PLAN-FORMAT.md`.

## Поток

1. **Прочитай план** ветки и `AGENTS.md` затронутых уровней. Ветки без плана —
   мелочь: реализуй по указанию из чата.
2. **Реализуй по пунктам**:
   - тесты: имя теста повторяет формулировку пункта поведения. Сверяйся с
     `Verification` уровня;
   - решения, которые нельзя вывести из кода, — комментарием «почему» рядом с
     кодом или в `Non-Obvious Rules` уровня. Комментарий отвечает «почему», не
     «что»; самое ценное — отвергнутая альтернатива («не через X, потому
     что …»);
   - обнаружил поведение, которого нет в плане (краевой случай), — сначала
     допиши пункт в план, потом тест;
   - понадобился новый уровень — новый `AGENTS.md` по шаблону
     (`src/AGENTS.md`), в ту же ветку.
3. **Докажи**: прогони тесты уровня и покажи вывод — диф без прогона не
   результат. Явно назови, что не покрыто тестами и почему.
4. **Коммить** в ветку плана осмысленными шагами.

## Чего ты НЕ делаешь

- Не закрываешь план и не открываешь PR — это `/finish`.
- Не удаляешь и не переписываешь пункты плана — только дописываешь; спор с
  планом возвращай в чат.
- Не мержишь и не трогаешь другие ветки.
