# Architecture Templates

Готовые скелеты архитектуры для `/architect`. Каждый шаблон — папка в
`src/templates/<имя>/` с набором `AGENTS.md`-скелетов по уровням. `/architect`
читает папку шаблона, раскрывает уровни под домен и создаёт файлы после согласия.

Формат уровня — один на всех, в `src/AGENTS.md`; шаблон задаёт только типовые
уровни и их наполнение для конкретной архитектуры. Пустых скелетов и уровней
«наперёд» нет — только те, что есть у образца.

## Список шаблонов

- `django-monorepo/` — монорепо: Django monolith (backend), SPA-клиент,
  инфраструктура. Образцы: `pg`, `fitness`.

Чтобы добавить шаблон — создай папку с тем же дифом поправь `install.sh`
(копируются все папки и файлы шаблонов автоматически) и упомяни в этом README.
