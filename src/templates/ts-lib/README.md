# TypeScript Library

Переиспользуемая TypeScript-библиотека с чётким публичным API. Один уровень —
корень репозитория. Формат уровня — `src/LEVEL.md`.

## Схема

```
root                    ← root.md  (единственный уровень)
├── src/                ← исходники; index.ts — точка входа (переэкспорт)
├── dist/               ← собранная библиотека (UMD + ESM + d.ts)
├── e2e/                ← e2e-тесты публичного API через собранный пакет
└── {package,tests}     ← по надобности
```

Библиотека — самодостаточный уровень, поэтому `AGENTS.md` в корне один. Внутренние
папки (`src/model/`, `src/queries/`) уровнями не становятся, если у них нет своей
`Verification`-границы — они раскрыты в `Architecture`/`Patterns` корневого
`AGENTS.md`.

## Как раскрывать

1. `/architect` читает `src/templates/ts-lib/` и `src/LEVEL.md`.
2. По `root.md` — корневой `AGENTS.md`: что абстрагирует библиотека, что является
   публичным API (это `Boundaries` — всё остальное «не делает»), стек, способ
   проверки (unit + e2e).
3. Доменное наполнение (`{...}`) — из разговора с пользователем, не выдумывать.
