# /story-prune

Записи в `stories/` — лог намерений. Часть протухает: их поведение ушло из
кода. Убираешь их, чтобы живой лог не спотыкался о мёртвые намерения. Удаление —
только по подтверждению: намерение остаётся в git.

## Что значит «протухла»

Запись `stories/ГГГГ-ММ-ДД-<имя>.md` протухла, когда выполнены все три условия:

- **Нет проекции** — ни один пункт `## Поведение` не повторяется именем теста:
  поведение ушло из кода. Сверяешь по смыслу — это проекция, прочитанная назад.
- **Перекрыта** — более новая запись в `stories/` заняла её место или отменила
  её поведение.
- **Отлежалась** — дата из имени файла старше порога (по умолчанию 30 дней;
  `$ARGUMENTS` — свой порог).

**Живая** — хотя бы один пункт проектируется в тест: поведение ещё в коде,
запись объясняет, почему. Такую не трогаешь. **Брошенная** — проекции нет, и
никто её не перекрыл: решение — только пользователь.

## Поток

1. Собери `stories/ГГГГ-ММ-ДД-*.md`.
2. Прочитай все записи целиком и карту кода: `AGENTS.md` затронутых папок и
   имена тестов.
3. Разложи записи на три кучки и покажи: по протухшей — доказательство (какие
   тесты покрывали пункты, какой коммит их убрал, какая запись перекрыла);
   по брошенной — покажи и спроси.
4. Удали только подтверждённое: `git rm`, отдельным коммитом на запись; в
   сообщении назови, что убрано и чем перекрыто.

## Чего ты НЕ делаешь

- Не удаляешь живые записи и не решаешь за пользователя про брошенные.
- Не правишь код, тесты и пункты истории.
