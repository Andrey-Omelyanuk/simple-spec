# Simple Spec

A command set for an AI agent (opencode, Claude Code, Cursor): understanding of a
task is captured as a **story**, the story is implemented as **code**, and truth
lives in the code and tests. The kit is read by an agent in a foreign project, so
it is translated. The language is chosen at install time with `-l` (default `en`)
and remembered by the manifest.
