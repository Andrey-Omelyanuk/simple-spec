# Simple Spec - простой способ разработки через ИИ агенты. 

## Определения 
**Spec** это центральная сущьность которая описывает чего мы хотим.
**ToDo** это список из того как мы будем реализовывать **spec**.
**UserStory** это истории от лица пользователя, того что он может или не может делать. Опционально.

## Режимы 
Агент переключается между режимами явно. Параллелизм запрещён.

**/think** режим которвый помогает обсудить с ИИ чего мы хотим и формирует результат только в `spec.md` и `todo.md`.
**/user-story** режим который помогает обсудить с ИИ что может делать пользователь и формирует результат только в папке `user-story`, 
где каждый файл это один домен с набором историй. Финальным шагом являеться переход в **/think** режим для формирования `spec.md` и `todo.md`.
**/do-it** режим который запускает агента который начинает выполнять задачи в `todo.md`. Каждая задача начинаеться с чистого контекста.
**/import** вспомогательный режим для миграции в **Simple Spec**, он формирует `spec.md` из существующей кодовой базы. 
**/audit** вспомогательный режим который помогает найти расхождения между `spec.md` и кодовой базой, итогом должны быть задачи в `todo.md` которые описывают как устранить эти расхождения.

## 1. Фундаментальная идея
- Система превращает хаотичную разработку в управляемый конвейер: Spec (потребность, что нужно) → Todo (план, как будем реализовывать) → Code (реализация).
- Файлы как контракт: Единственный источник истины — текстовые файлы (`spec.md`, `todo.md`). Никакого скрытого состояния.
- Локальность: Агент работает строго в контексте директории описанных в `spec.md`.
- Удаление задач: Выполненная задача физически удаляется из `todo.md`. История сохраняется в Git.

Правило: spec.md и todo.md всегда лежат рядом (1:1). Дочерние спеки наследуют ограничения родителей, но не дублируют их.
Агент всегда исполняеться только внутри текущего `spec.md` контекста.

agent.md всегда рядом со spec.md, вместо скилов мы там описываем возможности агента

spec.md всегда описывает директории к которым он относиться, вложеные директории может иметь свой набор `spec.md`, `todo.md` и `agent.md`
