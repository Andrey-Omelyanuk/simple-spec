# Меч

Оружие персонажа для ближнего боя. Замах — по нажатию пробела.

## Поведение
- Пока не бьют — меч не активен, ничего не происходит.
- Нажат пробел → персонаж делает замах в сторону последнего движения. Если ещё не
  двигался — бьёт вправо.
- Задел врага рядом (Патрульного или Кактус) → тот исчезает с карты.
- Враг слишком далеко → остаётся невредим: меч бьёт только вблизи перед персонажем.
- После удара — короткая перезарядка: сразу повторить удар нельзя, перезарядка
  проходит сама.

## Связи
Принадлежит Персонажу. Убивает Кактус и Патрульного.
