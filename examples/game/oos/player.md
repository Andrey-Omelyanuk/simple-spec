# Персонаж

Герой, которым управляет игрок: ходит по карте с видом сверху, дерётся, теряет и
восстанавливает здоровье.

## Состояния
- Здоровье: число от 0 до 100 (максимум — 100).
- Обычный / мигает после урона (пока мигает — неуязвим около секунды).

## Поведение
- Стоит на месте, пока игрок не задал направление.
- Идёт в одну из восьми сторон, пока игрок держит направление; по диагонали — не
  быстрее, чем по прямой.
- Упирается в стену и не проходит сквозь; идя по диагонали вдоль стены — скользит
  вдоль неё, а не застревает.
- Не выходит за край карты.
- Появляется со здоровьем 100.
- Получает урон → здоровье уменьшается, но не ниже 0.
- Здоровье никогда не поднимается выше максимума, из какого бы источника ни лечили.
- Здоровье упало до 0 → исчезает и появляется в начальной точке с полным здоровьем.
- После урона мигает и около секунды неуязвим: касание источника урона в это время
  не отнимает здоровье. Мигание закончилось → урон снова проходит.

## Внешний вид
При ходьбе перебирает ногами; стоя на месте — ноги замирают.

## Связи
Ходит по Карте. Получает урон от Кактуса и Патрульного. Лечится Сердечком. Бьёт
Мечом. Собирает Монетки. Пользуется Порталом, проходит в Дверь на следующий Уровень.
