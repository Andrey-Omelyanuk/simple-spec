# Сердечко

Лежит на карте, восстанавливает здоровье подобравшему.

## Поведение
- Лежит на карте с начала игры.
- Персонаж с неполным здоровьем подошёл → восстанавливает ему 10 здоровья и
  исчезает навсегда.
- Персонаж с полным здоровьем подошёл → остаётся лежать, здоровье не меняется.

## Связи
Лежит на Карте. Лечит Персонажа (тот сам следит, чтобы здоровье не превысило
максимум).
