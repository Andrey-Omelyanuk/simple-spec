# Магазин

Выделенная прямоугольная область на карте с предметами для продажи.
Один магазин на каждом уровне.

## Поведение
- Прямоугольная зона на карте, внутри которой лежат предметы с ценами.
- Сейчас один предмет — Меч за 3 монетки (удваивает дальность удара навсегда).
- Персонаж касается предмета → если счёт ≥ цены, покупает: счёт уменьшается
  на цену, предмет исчезает из магазина навсегда (повторно купить нельзя).
- Не хватает монет → ничего не происходит, предмет остаётся.

## Связи
Стоит на Карте (на каждом уровне). Персонаж заходит и покупает предметы,
тратя Монетки (Счёт). Меч из магазина усиливает Меч персонажа.
