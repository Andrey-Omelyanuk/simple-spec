# Sim (игровая логика)

## Overview
Чистая модель игрового мира и правил: состояние, движение, коллизии, враги, урон.
Здесь живёт «мясо» большинства историй.

## Boundaries
Делает: хранит и пересчитывает состояние мира по входу и времени.
Не делает: не рисует, не читает клавиатуру, не играет звук, не трогает DOM/Canvas.

## Tech Stack
TypeScript без рантайм-зависимостей. Тесты: Jest.

## Architecture
```
sim/
  world.ts       состояние мира (сущности, карта)
  update.ts      шаг симуляции: (state, input, dt) → state
  collision.ts   разрешение столкновений со стенами/сущностями
```
Файлы заводим по мере появления историй, не наперёд.

## Patterns
- Шаг мира — чистая функция вида `update(state, input, dt) → state`. Один вызов =
  один тик; никакого внутреннего цикла.
- Вход (`input`) и время (`dt`) приходят только параметрами.

## Non-Obvious Rules
- **Детерминизм.** Никаких `Date.now()`, `performance.now()`, `Math.random()`.
  Время — через `dt`, случайность — через инъектируемый `seed`/генератор.
  Одинаковый вход → одинаковый выход, всегда.
- Запрещены импорты из `engine` и любые браузерные API.

## Verification
- **Unit (Jest):** файл рядом с кодом, `update.test.ts` и т.п.
- **Связь с историей:** в начале теста — ссылка на историю: `// story: <unique-name>`.
- **Как строится тест:** прогоняем фиксированную последовательность входов и `dt`
  через `update`, проверяем итоговое состояние. Благодаря детерминизму тест
  стабилен без моков времени/случайности.
- **Критерий готовности:** каждый сценарий истории покрыт таким прогоном; всё зелёное.

## Dependencies
