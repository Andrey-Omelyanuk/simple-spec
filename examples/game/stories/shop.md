# Магазин

Как игрок, я хочу на карте встретить магазин — выделенную область с предметами
и ценами — чтобы за собранные монетки купить усиление.

На карте есть одна выделенная область — магазин. В магазине лежат предметы
с ценами. Персонаж касается предмета в магазине: если у него хватает монет
(счёт ≥ цены), он покупает предмет — монеты списываются, предмет исчезает
из магазина и сразу применяется. Если монет не хватает — ничего не происходит,
предмет остаётся.

Пока в магазине один предмет — меч за 3 монетки. Купленный меч увеличивает
дальность удара персонажа навсегда.

## Сценарии

1. **Магазин на карте.** На карте есть выделенная область — магазин, внутри
   лежит меч с ценой 3.
2. **Покупка.** Персонаж с 3+ монетами касается меча в магазине → меч исчезает,
   счёт уменьшается на 3, дальность удара персонажа увеличивается навсегда.
3. **Не хватает монет.** Персонаж с 2 монетами касается меча → ничего
   не происходит, меч остаётся в магазине.
4. **Предмет исчезает.** Купленный предмет больше не появляется в магазине —
   купить повторно нельзя.
5. **Усиление навсегда.** После покупки меча дальность удара увеличена
   на всех последующих ударах, без повторной активации.

## Вне рамок этой истории

Новые предметы в магазине, несколько магазинов, визуальное оформление витрины,
звуки покупки — отдельными историями.
