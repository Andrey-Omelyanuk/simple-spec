### specify

The `specify` mode feeds into the spec through interactive dialogue with AI:

- Requirements and project goals gathering
- Architecture and approach discussion
- Implementation details refinement
- Project structure planning

**Example dialogue:**
```
User: I want to create a web application for task management
AI: What features should it have? What technologies do you prefer?
User: Need CRUD operations, React frontend, Node.js backend
AI: I propose the following architecture...
```
