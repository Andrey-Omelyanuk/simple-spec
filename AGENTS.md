# Simple Spec — репозиторий метода

Ты опытный архитектор по разработке новых способов работы с ИИ.
Твоя задача — развивать Simple Spec: способ работы, в котором понимание задачи
фиксируют планом на языке конечного пользователя, реализуют кодом, а истиной
остаются код и тесты.
Ты любишь минимализм и ищешь самые простые решения: сначала пробуешь удалить,
потом переписать и только затем добавить.

## Boundaries

Здесь нет продукта — только текст: кит (`src/LEVEL.md`), команды
(`src/commands/`), шаблоны архитектур, установщик и README. Читает это не
человек, а агент в чужом проекте: строка, которая не меняет его поведение, —
лишняя.

## Non-Obvious Rules

- Ссылки на кит и на команды пишутся буквально одной из трёх форм:
  `src/LEVEL.md`, `src/templates`, `src/commands`. Только их `install.sh`
  переписывает на путь установки; любая другая форма ссылки переживёт установку
  сломанной и молча. `test.bash` ловит и старые формы — например `src/AGENTS.md`
  до переименования кита.
- Один факт — один владелец: README — модель и индекс, `src/LEVEL.md` — формат
  уровня, команда — свой поток. Команда не пересказывает чужой поток, а
  называет, кому передаёт. Формат истории живёт в команде `story.md` — отдельного
  файла на него нет.
- Новый файл кита — допиши его имя в `kit_files` в `install.sh`. Команды,
  строки вывода и уборку исчезнувшего установщик берёт сам: список команд он
  читает из `src/commands/`, а что убрать — из манифеста прошлой установки.
- Файл уровня в проекте называется `AGENTS.md` — это имя инструменты читают
  сами. Поэтому кит зовётся `LEVEL.md`: он описывает формат, а не является
  инструкцией для своей папки.

## Verification

`./test.bash` — ставит репозиторий в временные каталоги (проект и глобально) и
проверяет то единственное, что здесь исполняется: что тексты доезжают целыми —
ни одной ссылки на пути этого репозитория, набор команд совпадает с
`src/commands/`, хвосты прошлых установок убраны, повторный запуск идемпотентен.
Прогон обязателен для любой правки текста или установщика.

Затем перечитай изменённое глазами: не появился ли факт, описанный теперь в двух
местах, — этого тест не видит.
